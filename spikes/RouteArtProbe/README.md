# Route Art Probe（#105）

本番アプリとは独立した検証用アプリ。3枚のAI生成背景、架空の線、背景切替、HealthKitからの読み取りを試す。背景の出どころと利用条件の確認状況は `docs/route-art-spike.md` を参照。Simulator専用ボタンは架空のワークアウトとルートをSimulatorのHealthKitに追加するため、書き込み権限を要求する。本番機能の仕様ではない。

```sh
xcodebuild -project spikes/RouteArtProbe/RouteArtProbe.xcodeproj -scheme RouteArtProbe -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath build/RouteArtProbe build CODE_SIGNING_ALLOWED=NO
```

動作確認は専用Simulatorで行い、架空のランを追加後に「HealthKitのランを読み込む」を選ぶ。ルートなし、長いルート、途中で離れた点を含むルートの生成もSimulatorでのみ行える。追加のたびSimulatorのHealthKitに新しいランが残る。データの追加・読み取りの成否は別途記録する。実データを持つ端末に架空データを書き込まないよう、追加ボタンはSimulatorに限定する。

遅延追加の検証では「ルートなしランを追加」し、読み込み後に「直前のルートなしランにルートを追加」を押して再読み込みする。後から追加する架空ルートは区別用に61点。対象のランはアプリ起動中だけ保持し、再起動後は追加できない。HealthKitの書き込み権限が必要で、失敗した場合は案内を表示して再試行できる。

複数ルートの検証では「2本の架空ルート付きランを追加」を押す。1つの架空ランに121点と、同じ軌跡を間引いた61点のルートを順に保存する。区間が離れた実際のデータの代わりにはならない。両方の保存が成功した案内を確認してから読み込む。2本目の保存に失敗した場合は1本目のランとルートが残る。追加したデータは専用SimulatorのHealthKitに残る。

「離れた2区間の架空ランを追加」は同じ架空軌跡を61点と60点に分け、後半を経度方向に移動させて保存する。両方の保存成功後に読み込むと、各区間の間を結ばない表示を確認できる。これは人工的に作った欠損例で、実際のルートの順序や分断の正しさを保証しない。2本目の保存に失敗すると1本目は残る。

線の下に同じ線種の暗い縁を描く視認性の試案を含む。夕日背景とオレンジの点線ではプレビュー・写真保存を確認したが、縁は目立つ。他の組み合わせや実データでの視認性と見栄えは未検証であり、本番のデザインは未確定。

Simulator専用の「検証用にアプリ内へ保存」は表示中の完成画像をPNGとして試作のApplication Supportに追加する。「検証用の保存作品を見る」でHealthKitを読み直さず一覧表示する。画像はSimulatorに残る。これは容量と再起動後の閲覧を試すための最小実装で、削除、保存数の上限、効率的な一覧、ファイル保護、バックアップ・復元は未実装または未検証。本番用の保存機能として使わない。

保存作品一覧の「検証用の破損画像を追加」は画像として読めない架空ファイルを追加する。正常画像と共存させ、一覧が表示されるか確認するためのもの。追加したファイルも専用Simulatorに残り、試作からの削除はできない。ユーザーの作品や実機のデータには使用しない。

Simulator専用の「検証用にPNGとJPEGを比較」は現在の作品からPNGと品質0.85のJPEGを生成し、各バイト数とJPEG再読み込み画像を表示する。表示は比較ボタンを押した時点の画像で、設定変更後は再度押す。比較画像は保存せず、HealthKitの再読み込み開始時とバックグラウンド移行時に消す。結果は実機や本番形式の採用を保証しない。

試作の制限: 最新30件のみ検索。複数ルートは開始日時順（同時刻ならUUID順）にそれぞれ読み込み、ルート間を結ばない試案。並び順が実際の走行順になるとは限らず、空・重複・重なりや途中の取得失敗、負荷と実機での妥当性は未検証。離れた区間は人工的な1例のみ確認。読み込み開始後、前景でHealthKitのルート追加・削除を監視し、変化時にラン全体を再検索する試案を追加した。全ルートが対象で無関係な変更でも再検索するため、負荷と頻度は未評価。ワークアウト自体の変更の監視、削除時、別アプリ・実機での挙動は未検証。分断は仮の閾値による候補で、誤検出・見逃しがあり得る。未読込時はサンプル線を表示し、読み込み後の空や失敗時は線を出さず保存・共有を無効にする。バックグラウンド移行時に読み取り済みのルートを消し、前景復帰時に再取得する方式は検証用であり、本番の操作感や実機での挙動は未確定。線の色・見た目と画像の写真保存・共有は検証用。開始・終了地点周囲を隠す200mの試案は匿名化を保証しない。表示は実装の成立を保証しない。
