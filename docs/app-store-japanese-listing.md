# 日本語ストア情報・対応言語の更新（Issue #74）

## 現在の確認結果

2026-10-23に[日本ストア](https://apps.apple.com/jp/app/id6809106831)の実画面を確認した。アプリ名・サブタイトル・説明は日本語で、情報欄の対応言語は「英語」。スクリーンショットは3枚掲載されている。Connectで公開版`1.0 (3)`、プライマリ言語「日本語」を確認した。更新用`1.0.1`を作成し、日本語のサブタイトル・プロモーション用テキスト・説明・キーワード・更新情報を保存した。必須のDynamic Island搭載iPhone（中型ディスプレイ）枠に1206×2622の新スクショ3枚を登録し、開始→通知調整→実行中の順を確認した。既存の別サイズ画像は保持している。署名済みビルドと公開は未完了。ソースの次回バージョンは`1.0.1 (4)`とする。

本変更のソースは通知1本・10分単位の間隔・通知終了予定・メッセージ編集に対応している。ログ・サマリ・Live Activityは未実装なので紹介しない。以下はこのソースに対応する更新用素材であり、公開反映済みではない。

## 日本語メタデータ（入力用）

### 名前

ランニング補給タイマー

### サブタイトル

走る前に設定、補給のタイミングをお知らせ

### プロモーション用テキスト

自分で決めた補給のタイミングを、走行中のリマインダーに。通知間隔と通知を止める予定を選んで、ロング走やレースに備えましょう。

### 説明

走っている間、補給のタイミングを忘れてしまうことはありませんか。
ランニング補給タイマーは、自分で決めた補給予定をローカル通知で知らせる、シンプルなiPhoneアプリです。

・通知間隔と、通知を止める予定を選んで開始
・通知に表示する短いメッセージを変更
・経過時間と次の予定を画面で確認
・一時停止、再開、終了に対応
・前回の通知設定を端末内に保存
・通知を使わずタイマーだけでも利用可能

補給量や栄養に関する判断を指示するアプリではありません。ご自身の計画、体調、製品表示に合わせて設定してください。
通知の表示や音はiPhoneの通知設定、集中モード、消音などの影響を受けます。アプリを完全に終了すると、実行中のタイマーは続きから再開できません。

### キーワード

ランニング,補給,タイマー,マラソン,ロング走,リマインダー,ジェル,給水

### このバージョンの最新情報

アプリの対応言語を日本語として宣言し、日本語環境での表示設定を整えました。

## アプリ側の宣言と検証

- Xcodeプロジェクトの開発言語と既知の言語を`ja`へ変更する。
- `Resources/Info.plist`の`CFBundleLocalizations`に`ja`だけを宣言し、Debug/Release双方で生成Info.plistへ取り込む。
- システムの通知許可ダイアログやホーム画面の表示名も、既存のストア名に合わせて日本語で宣言する。
- 文字列は日本語のSwiftUIリテラルを継続使用する。英語UIの提供や機能・保存形式の変更は含めない。
- ビルド成果物の`CFBundleDevelopmentRegion = ja`、`CFBundleLocalizations = [ja]`を確認する。プロジェクト設定だけで公開ストアの対応言語が変わったとは判断しない。
- `make lint`、`make typecheck`、`make test`、`make build`を実行する。
- 日本語設定のSimulatorで、開始・通知調整・一時停止・再開・終了を操作し、システムの通知許可ダイアログと終了確認を確認する。

## ローカル確認結果（2026-10-23）

- `make lint`、`make typecheck`、`make build`: 成功。
- `make test`: iPhone 16・iOS 18.3.1で既存16ケース成功。
- `Release`の実機向け未署名ビルド: 成功。Debug/Release双方で日本語開発言語・対応言語・表示名と`1.0.1 (4)`を確認。
- iPhone 16 Pro・iOS 18.3.1（日本語）の開始、設定確定、一時停止、再開、終了確認と設定画面への復帰を確認。
- 通知許可システムダイアログの本文とアプリ表示名が日本語であることを確認。
- Simulatorでの確認のため、実機での通知音・振動・ロック配信や公開ストアの言語反映を検証済みとは扱わない。

## Connectでの反映手順・未完了項目

1. 公開中のバージョン・ビルド・既存素材を確認し、このソースとの差がないか照合する。
2. 「アプリ情報」で日本語ローカライズ・プライマリ言語を確認する。対応言語欄の修正と混同しない。
3. 次回更新の日本語欄に上記メタデータ・スクショを設定する（1.0.1に保存・登録済み）。名前の変更、追加機能の宣伝、RRM案内は今回含めない。
4. 公開済み版と重複しないバージョン・ビルド番号を決め、日本語宣言を含む署名済みReleaseアーカイブをアップロードする。今回のソースは1.0.1 (4)。アップロード前に、同じビルド番号が他の作業から先に使用されていないか再確認する。
5. TestFlight/実機QA・審査・公開の結果を#74と#76へ記録する。素材の準備やPRマージだけで#74を閉じない。
6. 公開後に日本ストアで説明・スクショ・対応言語「日本語」を確認する。

Connectの設定変更、素材アップロード、署名済み配布、公開反映は、実行できた時点でのみIssueのチェックを更新する。
