# ルートアート本体実装（#215）

ヘルスケアのランと経路を読み取り、地図を含まない作品を作成する。既存のタイマー・履歴とは独立した入口で、権限がなくても保存済み作品を閲覧できる。直近30件からルート付きランを探し、別のランも選択できる。読み取り拒否とデータがない状態は区別できない。

背景は外部素材を使わず、アプリ内で描く風景のイラスト3種類。写真風の背景は採用しておらず、以前の比較見本とは異なる。経路の全体の開始・終了を中心に半径約200mを初期設定で隠す試案を使用する。軌跡や記録から場所が推測される可能性は残り、匿名化は保証しない。分断の閾値、保護の距離・効果と表示は実ルートで検証できていない。

ユーザーの操作により、完成画像をApplication Support内にPNGで保存し、一覧・詳細・個別削除できる。写真への追加と共有は別の明示操作。生の座標はファイルとして保存しない。画像の削除は写真・共有先・既存バックアップにあるコピーには及ばない。Garminの経路がHealthKitにあるとは限らず、Garmin APIやGPXの読み込みは行わない。

## 公開前に残る確認

- 実機で作品ファイルの保護属性、バックアップ・復元、容量不足と削除を確認する。
- 写真風の背景を使う場合は使用条件の確認できる素材を用意し、線と文字の視認性を確認する。
- 実際のデータ処理に合わせて公開プライバシーポリシーとApp Privacyの回答、審査用説明を更新し、既存タイマー・通知・履歴を回帰確認する。アプリ内の説明更新だけでは公開ポリシーの更新完了を意味しない。
