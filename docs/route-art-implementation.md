# ルートアート本体実装（#215）

ヘルスケアのランと経路を読み取り、地図を含まない作品を作成する。既存のタイマー・履歴とは独立した入口で、権限がなくても保存済み作品を閲覧できる。直近30件からルート付きランを探し、別のランも選択できる。読み取り拒否とデータがない状態は区別できない。

背景はCC0の風景写真3種類。出典・加工方法は[同梱背景の記録](route-art-backgrounds.md)を参照。実際のランの景色とは限らない。経路の全体の開始・終了を中心に半径約200mを初期設定で隠す試案を使用する。軌跡や記録から場所が推測される可能性は残り、匿名化は保証しない。分断の閾値、保護の距離・効果と表示は実ルートで検証できていない。

ユーザーの操作により、完成画像をApplication Support内にPNGで保存し、一覧・詳細・個別削除できる。写真への追加と共有は別の明示操作。生の座標はファイルとして保存しない。画像の削除は写真・共有先・既存バックアップにあるコピーには及ばない。Garminの経路がHealthKitにあるとは限らず、Garmin APIやGPXの読み込みは行わない。

## マージ後の本体確認（2026-11-15）

main `1f24ef8` の本体を、iPhone 17 / iOS 26.2の専用Simulatorで署名付きビルドし、`xcodebuild test` を実行。Swift Testing 48件すべて成功した。起動後の初回案内と、初回案内を起動引数で省いたホームのルートアート入口を表示確認した。署名付きのiPhone向けビルドも成功し、署名のHealthKit権限が有効であることを確認した。作品作成画面の操作・HealthKitの実ルート・画像の保存や共有、実機はこの確認に含まない。

公開時は [App Privacy 回答案](app-store-privacy.md) を照合する。特にHealthKit由来の画像について、任意の共有先への送信およびiCloudバックアップとAppleの制約の関係は未確認。ルート画像の取り扱いを適合済みとして提出しない。
